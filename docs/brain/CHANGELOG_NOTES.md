# Changelog & Historical Notes (히스토리 노트)

이 문서는 `brain` 폴더와 관련된 작업 방식의 진화 과정을 기록합니다.

## 프로젝트 히스토리 요약
*기록 근거: 현재 폴더 구조 및 기존 문서(architecture-report.md 등) 분석*

- **초기 단계**: 에이전트의 작업 기록이 파편화되어 있었으며, 주로 개별 소스 코드 수정 위주로 진행됨.
- **Phase 1 (Planning 도입)**: `implementation_plan.md` 도입을 통해 대규모 변경 전 사용자의 명시적 승인을 받는 절차가 정착됨.
- **Phase 2 (Knowledge System 통합)**: 반복되는 아키텍처 규칙과 데이터 스펙을 Knowledge Item(KI)으로 자산화하여 에이전트 간 지식 전수 효율성을 높임.
- **현재 (Handbook 수립)**: 외부 개발자와 다른 AI 에이전트가 이 구조를 이해할 수 있도록 공식 핸드북을 docs 하위에 구축함.

## 진화 과정상 특이사항
- **확실하지 않음 (근거 부족)**: 구체적인 프로젝트 관리 도구나 외부 이슈 트래커와의 자동 연동 여부는 현재 파일 시스템상에서 확인되지 않았습니다.
- **관찰된 패턴**: `media/` 폴더의 생성 빈도가 높아짐에 따라 시각적 증빙 자료(walkthrough.md)의 중요성이 강화되고 있는 것으로 보입니다.
