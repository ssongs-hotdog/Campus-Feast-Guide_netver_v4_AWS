# Brain Folder Handbook (브레인 폴더 핸드북)

## 목적
이 문서는 Antigravity AI 에이전트와 개발자가 협업하며 생성되는 모든 지식, 계획, 작업 기록의 중심지인 `brain` 폴더의 역할과 활용법을 설명합니다. 이 폴더는 프로젝트의 **'AI 가청 기억(Agentic Memory)'** 및 **'실행 계획소'** 역할을 수행합니다.

## 한 줄 요약
> **"AI 에이전트의 모든 의사결정과 지식 히스토리가 저장되는 영속적 데이터 저장소"**

## 언제/왜 쓰는가?
- **AI 온보딩**: 새로운 AI 에이전트가 투입되었을 때, 과거에 어떤 의사결정이 내려졌고 현재 프로젝트 상태가 어떠한지 즉시 파악하기 위해 사용합니다.
- **작업 계획 및 승인**: 복잡한 기능을 구현하기 전, `implementation_plan.md`를 통해 사람 개발자에게 검토를 받고 승인된 경로로 작업을 진행하기 위해 사용합니다.
- **지식 자산화**: 프로젝트의 아키텍처, 데이터 스펙, 트러블슈팅 경험을 휘발되지 않는 지식 아이템(KI)으로 저장하여 지속 가능한 개발 환경을 구축합니다.

## 구조 (개요)
브레인 폴더는 크게 다음 세 가지 영역으로 나뉩니다.
1. **작업 세션 (Conversations)**: 각 대화/태스크별 작업 로그 및 산출물
2. **지식 베이스 (Knowledge)**: 프로젝트 전반에 걸친 정제된 지식
3. **태스크 관리 (Task)**: 현재 진행 중인 작업의 진행 상황 및 체크리스트

## 사용처
- **Antigravity 에이전트**: 모든 도구 활용과 코드 수정을 하기 전, 이 폴더의 정보를 읽어 현재 맥락을 파악합니다.
- **개발자**: AI가 수행한 작업의 의도를 확인하고, `walkthrough.md`를 통해 결과물을 검증합니다.

## 확장법
- 새로운 지식(KI)은 기존 문서를 업데이트하거나, 새로운 주제의 마크다운 파일을 지식 저장소에 추가함으로써 확장합니다.
- 태스크 체크리스트를 업데이트하여 프로젝트의 진행 상태를 동기화합니다.

## 트러블슈팅
- 만약 AI 에이전트가 이전 작업 내용을 기억하지 못한다면, 관련 세션 ID의 `task.md`나 `implementation_plan.md`를 다시 한번 상기시키거나 링크를 제공하십시오.
