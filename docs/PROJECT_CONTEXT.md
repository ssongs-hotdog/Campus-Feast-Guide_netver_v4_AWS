# PROJECT_CONTEXT (Verified SSOT)

## 문서 목적
이 문서는 코드만으로 복원하기 어려운 HY-eat의 제품 의도/브랜드 원칙을 공식 기준으로 고정한다.

## 서비스 미션
HY-eat은 한양대학교(서울) 캠퍼스 식당의 혼잡/대기 문제를 줄이기 위해, 식당/코너별 예상 대기시간(`estWaitTimeMin`)과 메뉴 정보를 제공하는 서비스다.

## 제품 가치
- 사용자: 덜 붐비는 코너를 선택해 대기시간을 줄임
- 운영자(Admin): 실시간 관제와 운영 판단(혼잡, 메뉴 운영 상태)을 지원
- 심사/공모전 맥락: "실서비스처럼 보이는 완성도"를 우선 확보

## 브랜드/UX 원칙 (비코드 의도, 필수 유지)
- 톤: 프리미엄 미니멀 (과한 장식보다 명확한 정보 전달)
- 컬러: 한양 블루 중심 포인트 사용
  - 코드 근거: 상단 앱바에서 `#0E4A84` 사용 (`client/src/components/TopAppBar.tsx`)
- 탭 일관성: 각 탭의 좌상단 제목/설명 위치는 대시보드 기준 정렬 규칙을 유지
  - Admin 헤더 컴포넌트 기준 근거: `client/src/admin/components/AdminPageHeader.tsx`
- Admin UX 우선순위: 화려함보다 운영 효율, 안정성, 오류 예방

## 범위 정의
- 본 문서는 "의도/방향" SSOT다.
- 구현 상세(엔드포인트, 데이터 계약, 배포)는 아래 문서가 우선한다.
  - `docs/ARCHITECTURE_VERIFIED.md`
  - `docs/DATA_CONTRACTS_VERIFIED.md`

## 주의
본 문서의 브랜드/제품 의도는 코드 리팩터링 시에도 유지되어야 하며, 변경 시 기획 합의 후 문서를 먼저 갱신한다.
